# Credits

The pages are a static Vite build. The sentences, prices, results, and the Ed25519 check are original to A3P. The interface uses free, open-source components from the libraries below. Paid or closed components were not used.

## Inter

The wordmark and the page type are Inter, the Latin subset from Fontsource (Inter 5.2.8), which distributes the Google Fonts build. Inter is licensed under the SIL Open Font License 1.1. The font files are self-hosted. See `FONTS.txt`.

## Source Serif Pro

The G3 badge uses Source Serif Pro for the level and the agent name. The files are the Latin subset from Fontsource (`source-serif-pro` 5.2.5), which distributes Adobe’s design, under the SIL Open Font License 1.1. Headings on the page stay in Ciottolo. Body text stays in Inter.

## daisyUI

Navbar, buttons, the language control, form fields, and tables use [daisyUI](https://daisyui.com) 5 (MIT). Copyright Pouya Saadeghi. <https://github.com/saadeghi/daisyui>

## HyperUI

The price cards follow the free marketing pricing block at <https://hyperui.dev> (`marketing/pricing/1`): a rounded bordered card, a strong price, and a check beside the line of copy. The prices and sentences are A3P’s. [HyperUI](https://github.com/markmead/hyperui) is MIT. Copyright (c) Mark Mead.

## Magic UI

[Magic UI](https://magicui.design) components, MIT, Copyright Magic UI. Source: <https://github.com/magicuidesign/magicui>

- Blur Fade, for the short entrance of the hero and section headings
- Number Ticker, kept as the place the scores are printed. The count-up is not used: 82, 93, and 0 are plain text
- Border Beam, recolored to the site ink, on the measured quote

## Aceternity UI

Background Gradient, from the public registry at <https://ui.aceternity.com/registry/background-gradient.json>. Author: Manu Arora \<hi@manuarora.in\>. It wraps the Business price only. The motion is slower, and the colors are the site palette.

The Aceternity Pro licence (<https://ui.aceternity.com/licence>) was not purchased and does not cover this file. The component is used inside this site. It is not redistributed as a component library.

## 21st.dev and Hirael

The before/after block is Comparison 03 by Mohammad Shehadeh, MIT, Copyright (c) 2026 Mohammad Shehadeh.

- Upstream: <https://github.com/MohammadShehadeh/hirael>
- Registry: <https://hirael.com/r/comparison-03.json>
- 21st.dev lists the same block as `hirael/comparison-03` under the MIT licence

The 21st.dev install API requires a key, so the file was taken from that MIT upstream rather than from a private registry. The Radix button and toggle were replaced with daisyUI controls. The sentences describe the receipt against the empty outbox.

The block’s entrance classes come from `tw-animate-css` (MIT). The icons come from `lucide-react` (ISC). Motion comes from the `motion` package (MIT).

## What this page does not say

A matching badge is an assessment of one sample under A3P Method v1.0. It is not a certification, and it does not mean the agent is safe.
