## Limits

The live MCP scan and the adaptive attacker are not extra rows in this matrix. They do not raise the catalog count.

The scan can send every local archive row (`--probe all`). The default is still three. Destructive tools are called only with `--invoke-destructive`. The demo's shell records the argument and does not execute it. A third-party destructive tool still runs inside the sandbox. Poison phrases, a description-hash change, a secret pattern, and an injection phrase are the checks. They are not Invariant's rule language.

The adaptive attacker can ask a model to write a turn in one of the eleven archive languages. Without a model, translation uses `src/a3p/corpus/probe_phrases.py`. Six languages are marked reviewed. Five are marked machine. A machine row is not a reviewed translation, and the table is not coverage of every archive row.

A code on a built-in scenario is still one oracle. The scan does not turn that code into a finished control.
